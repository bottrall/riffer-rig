    0.7.0 (2026-09-30)

    ⚠ BREAKING CHANGES

    • Riffer::Rig::CodingAgent, REPL, TokenTally and the UI namespace are removed, and the old CLI is replaced by the dispatcher. Embed a Runtime through Riffer::Rig::Loader.runtime instead of CodingAgent; the terminal UI classes now live under Riffer::Rig::Terminal. The bash tool now errors when its context has no :cwd.

    • DEFAULT_MODEL is gone; with no model the Loader asks the host to onboard and the null host’s refusal is a configuration error. The old Settings module API changes shape.

    • Riffer::Rig::Hosts::Base and Riffer::Rig::Events::Event are removed. A host is any object implementing the five host methods (Riffer::Rig::Hosts::_Host); drop the superclass. A custom event drops the superclass and super(), and includes Riffer::Rig::Events::Value for equality.

    Features

    • /model switches the model for the current Runtime (#193) (f888972)

    • bundle Agent Skills with /skill: commands over the skills seam (#201) (e14844d)

    • bundle AGENTS.md as the agents_md prompt section (#198) (e2e9141)

    • bundle read, write, edit and bash as extensions (#195) (d5c9ffe)

    • bundle the MCP client over the mcp seam (#202) (c2fc42f)

    • isolate extension load errors and check requires (#192) (0aac3bf), closes #114

    • lifecycle, vetoable and observe hooks plus the stream passthrough (#194) (206d349)

    • Loader builds a Runtime from settings, credentials and the bundle (#205) (01170fe), closes #123

    • namespaced extension settings (#196) (dc16a84), closes #117

    • rebuild the registrar in place (#199) (f4b742b)

    • runtime commands with run_command and the command context (#190) (159d007), closes #111

    • snapshot and restore a Runtime (#200) (aaad579)

    • Terminal drives a Loader-built Runtime (#206) (f805db6)

    • token tally and pricing behind the Runtime (#189) (1ccde0d)

    Bug Fixes

    • run steep check without attaching to a language server (#197) (4f0b92e)

    Code Refactoring

    • interfaces over inheritance, POROs over hashes, new cops (#204) (7fda3e3)

    0.6.0 (2026-09-27)

    ⚠ BREAKING CHANGES

    • the flat {"anthropic": "sk-..."} auth.json shape is no longer read, with no migration. Stored keys must be re-entered or rewritten as {"anthropic": {"type": "api_key", "api_key": "sk-..."}}.

    • Riffer::Rig::Host is removed. A host subclasses Riffer::Rig::Hosts::Base and implements all five methods; the null host is Riffer::Rig::Hosts::Null.

    Features

    • add the rig event vocabulary and close (#179) (35bfa6e)

    • cancel a running turn from any thread (#186) (ec68188)

    • deps: upgrade riffer to 0.49.0 (#188) (821413f)

    • named prompt sections rendered every turn (#184) (d190a07)

    • provider setup table and typed auth.json credentials (#185) (0a30c35)

    • store credentials on the Runtime (#181) (474a515)

    Code Refactoring

    • make the host contract the abstract Hosts::Base (#183) (3fd4f14)
