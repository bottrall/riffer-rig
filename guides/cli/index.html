Using the terminal · 05

Command line

On this page
  • Flags
  • Environment variables
  • Exit codes
riffer [options]            open the terminal
riffer -p [prompt] [options] run one prompt headless and exit
riffer acp                  serve the agent over ACP on stdio

riffer acp takes no options; an editor configures it through the same settings as the terminal (ACP).

Flags

Flag Effect Terminal -p
--model provider/name the model for this run (precedence) ✓ ✓
--reasoning LEVEL the reasoning level for this run: off low medium high xhigh max ✓ ✓
--tools read,bash only these tools, by identifier (Tools) ✓ ✓
--max-steps N stops a turn after N model calls ✓ ✓
--no-extensions skips the rig.rb files and gem autoload; bundled extensions still load ✓ ✓
--no-skills leaves out Agent Skills ✓ ✓
--no-agents-md leaves out AGENTS.md ✓ ✓
--no-save neither saves this session nor reads saved ones (Sessions) ✓ ✓
-c, --continue continues the most recent session in this directory (Sessions) ✓ ✓
-r ID, --resume ID resumes the session with that id ✓ ✓
-r, --resume (no id) opens the session picker ✓  
-p, --print runs one prompt with no terminal (Headless)   ✓
--json streams every event as NDJSON instead of the reply text   ✓
--verbose adds a one-line trace of each tool call to stderr   ✓
--job-idle-timeout SECONDS how long to wait for a background job to exit (default 600, 0 for no limit)   ✓
-h, --help prints the usage ✓ ✓
-v, --version prints the version ✓ ✓

Environment variables

Variable Effect
RIFFER_MODEL the model, below --model (precedence)
RIFFER_REASONING the reasoning level, below --reasoning
NO_COLOR turns colour off in the terminal

Each provider’s credential variables are listed in Providers.

Exit codes

Headless runs exit with a code that says how the turn ended; Headless has the table.
