The documentation

riffer, in your terminal and in your process.

Own your harness.

riffer rig is a general-purpose agent for Ruby developers who want to own their harness. It runs in the terminal and inside any Ruby process, you extend it in Ruby, and it ships a coding toolkit as its default bundle.

A harness you own

One small agent, two ways in — the terminal or your own Ruby code — and every seam open to a Ruby class.

i

TerminalThe REPL

Run riffer in any project and chat with it, with slash commands and skills.

ii

TerminalProviders

Anthropic, OpenAI, Gemini, OpenRouter, Azure OpenAI and Amazon Bedrock, picked with one provider/name string.

iii

RubyEmbedding

The runtime is separate from the terminal, so a Rails app, a script or a job can drive it in-process.

iv

RubyExtensions

Tools, commands, prompt sections and hooks are ordinary Ruby, registered from a rig.rb.

v

BundledCoding toolkit

Read, write, edit and bash ship as the default bundle, and any of them can be replaced.

vi

BundledSkills & MCP

Agent Skills directories and MCP servers plug in through settings, on riffer's own clients.
